# Contributing

Open an issue before starting a substantial change. Keep pull requests focused, include tests for behavior changes, and do not add secrets, private infrastructure details, personal data, generated media, or model weights.

Contributions use the Developer Certificate of Origin. Add a sign-off to every commit:

```text
Signed-off-by: Your Name <you@example.com>
```

Create signed commits with `git commit -s`. The sign-off certifies that you have the right to submit the contribution under this repository's license.
